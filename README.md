# PDF portfolio page

A one-page site that shows whatever PDF you put in this repository.

- **One PDF:** it fills the page.
- **Several PDFs:** a row of buttons at the top switches between them.
- **Names:** each PDF's file name becomes its title (`birmingham_map.pdf` shows as "Birmingham map").
- **Links to one PDF:** `…/?pdf=birmingham_map.pdf` opens that file directly.

## Adding a PDF

On the repository page on GitHub, choose **Add file → Upload files**, drag the PDF in and click **Commit changes**. It appears on the site within a minute or two.

Put PDFs in the top level of the repository, not in a folder.
